# D1 技术验证

## 目标

验证 JobLoop 的核心桌面路线：

- Electron 应用可启动。
- 第三方招聘网站可在应用内打开。
- 用户可自行完成登录。
- 登录 Session 可以跨重启持久化。
- Agent 工作台可通过受控桥接读取当前页面标题和可见正文。
- 招聘网站页面不能直接访问 Node.js 或本地数据库。

## 运行

```powershell
npm install
npm run dev
```

自动验证构建和内嵌页面读取：

```powershell
npm run smoke
```

默认打开 `https://www.zhipin.com/`。也可以通过环境变量指定其他启动网址：

```powershell
$env:JOBLOOP_START_URL = "https://www.liepin.com/"
npm run dev
```

## D1 验收步骤

1. 启动应用，确认左侧出现招聘网站。
2. 在招聘网站内完成登录。
3. 进入一个真实岗位详情页。
4. 点击右侧“读取当前页面”。
5. 确认标题、URL、正文长度和正文预览有内容。
6. 关闭应用并重新运行 `npm run dev`。
7. 确认招聘网站仍保持登录。

## 当前边界

- 只读取当前顶层页面，不扫描其他标签页。
- 点击读取前不会主动分析网页。
- 不保存 Cookie 内容、密码或认证头。
- 不执行点击、填写、发送或投递。
- 不向招聘网站页面注入模型 API 密钥。
