# JobLoop

面向个人求职者的本地 AI 求职工作台。

JobLoop 的目标是把求职过程串成一条可持续使用的闭环：

```text
简历 → 岗位采集 → 匹配评估 → 打招呼 → 投递跟踪 → 面试准备
```

当前状态：D2 应用外壳与 IPC 加固已验收完成，下一步进入岗位采集与结构化 `JobPosting`。

## 产品定位

JobLoop 不是自动投递机器人，也不是只负责聊天的求职助手。它是一个由用户主导的桌面工作台：

- 用户在应用内登录招聘网站并浏览岗位。
- Agent 在用户明确触发后读取当前岗位。
- 用户确认结构化岗位信息后，Agent 进行分析和建议。
- 发布、填写、发送等有副作用的操作必须由用户确认。
- 用户的简历、岗位和投递数据默认保存在本地。

## MVP 范围

- Electron 内嵌浏览器，支持一个招聘网站及持久登录。
- 当前岗位一键提取，并允许用户修改提取结果。
- 简历上传、结构化候选人画像和证据确认。
- 岗位匹配评分、风险提示和置信度。
- 基于简历与 JD 生成打招呼语。
- 投递记录、状态历史、下一步行动和 Excel 导入。
- 基础投递数据面板。
- 技术面试、行为面试和按住说话的语音输入。
- Function Calling、流式执行事件、一个实际可用的 MCP Server 和自定义 Skills。

## 暂不实现

- 自动登录、自动投递或自动发送招聘消息。
- 批量爬取招聘网站。
- 第一版同时支持多个招聘网站。
- 全双工语音、实时打断和语音输出。
- 多 Agent 框架。
- 没有明确需求驱动的 RAG 或向量数据库。
